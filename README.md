# 🌍 COVID-19 Analysis & Prediction Dashboard

An end-to-end **Data Science + Web App project** that analyzes global COVID-19 trends and predicts future cases using Machine Learning.

---

## 🚀 Project Overview

This project focuses on:

* 📊 Analyzing COVID-19 trends (Confirmed, Deaths, Recovered)
* 📈 Creating interactive visualizations
* 🌍 Visualizing global spread using maps
* 🔮 Predicting future cases using **Facebook Prophet**
* 🖥️ Building a web dashboard using **Streamlit**

---

## 🧠 Tech Stack

* **Python**
* **Pandas** – Data processing
* **Plotly** – Interactive visualization
* **Prophet** – Time series forecasting
* **Streamlit** – Web application

---

## 📂 Dataset

* COVID-19 dataset containing:

  * Date
  * Country/Region
  * Confirmed cases
  * Deaths
  * Recovered cases

---

## 📊 Features

### 🔹 Data Analysis

* Global trend analysis
* Country-wise filtering
* Daily case calculation

### 🔹 Visualizations

* Line charts for trends
* Correlation insights
* Choropleth world map 🌍

### 🔹 Prediction

* Time-series forecasting using Prophet
* Predicts next **7 days cases**

### 🔹 Web Dashboard

* Interactive UI with Streamlit
* Real-time filtering
* Live predictions

---

## 🖥️ Demo (Local)

Run the app locally:

```bash
streamlit run app.py
```

Then open:

```
http://localhost:8501
```

---

## ⚙️ Installation

Make sure you have Python (3.10–3.12 recommended)

Install dependencies:

```bash
pip install streamlit pandas plotly prophet
```
